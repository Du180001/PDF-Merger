# CHANGELOG Indev.0.1

Basicamente, é um sistema feito para Windows, sem otimização ou estilização, apenas o sistema. Tanto que chamo essa versão de Indev.0.1

O sistema tem o mínimo de mecanismos possiveis para funcionar, mas resumindo bem o que acontece, funciona assim:
* Você coloca seus arquivos no site
* O site envia seus arquivos para o app.py (back-end)
* O back-end coloca seus arquivos na pasta uploads
* O back-end faz uma função nessa pasta que fundi todas e joga na pasta download
* O front-end acessa o arquivo dessa pasta e te permite fazer o Download
